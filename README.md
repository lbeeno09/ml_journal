# Note Order for Papers
For the sake of my training, I will roughly follow this order but it will not be strict. A Lot of the time Ill simply read in order. In either case, when equations or algorithms are shown, they will be the main focus of the paper.

1. Abstract
	- What kind of topic is this paper about?
2. Conclusion
	- Roughly discuss the result of this paper
3. Introduction
	- Background of the topic, from its inception to importance
4. Related Works
	- Previous works and their imperfections
5. Methodology
	- How did this paper resolve the issues proposed
6. Experiment
	- How was the method effective/ineffective?
